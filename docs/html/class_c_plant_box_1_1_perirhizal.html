Detailed Description

Wraps a MappedSegments (or specialisations MappedPlant, MappedRootsystem) and adds functions to help modelling the perirhizal zone.

Currently rather useless, main part is in Python (in Perirhizal.py), but perfomance critical methods could be implemented in C++
