\doxysubsection{Detailed Description}
The dynamic \mbox{\hyperlink{classaabb_1_1_a_a_b_b}{AABB}} tree. 

The dynamic \mbox{\hyperlink{classaabb_1_1_a_a_b_b}{AABB}} tree is a hierarchical data structure that can be used to efficiently query overlaps between objects of arbitrary shape and size that lie inside of a simulation box. Support is provided for periodic and non-\/periodic boxes, as well as boxes with partial periodicity, e.\+g. periodic along specific axes.
