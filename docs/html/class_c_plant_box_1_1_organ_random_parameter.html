Detailed Description

Contains a parameter set describing as single sub type of an organ, specific parameters are then created with realize().

Organizes parameters in hash-maps for scalar double and scalar int values. For this reason derived classes getParameter(), toString(), readXML(), and writeXML() should work out of the box. For other parameter types the methods must be overwritten, see e.g. RootRandomParameter.

The factory function copy() has to be overwritten for each specialization.

std::shared_ptr< OrganSpecificParameter > CPlantBox::OrganRandomParameter::realize ( )
virtual

creates a specific organ from the root parameter set

An organ specific parameter set (OrganParameter) is created from the general parameter set (OrganTypeParameter). In the specializations of this class, random variables are drawn from their distributions.

Normally, both OrganParameter, and OrganTypeParameter are constant over the organ life time.

Returns
The organ specific parameter set (each organ has exactly one set), ownership is passed to caller
