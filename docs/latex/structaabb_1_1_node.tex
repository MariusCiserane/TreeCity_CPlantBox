\doxysubsection{Detailed Description}
A node of the \mbox{\hyperlink{classaabb_1_1_a_a_b_b}{AABB}} tree. 

Each node of the tree contains an \mbox{\hyperlink{classaabb_1_1_a_a_b_b}{AABB}} object which corresponds to a particle, or a group of particles, in the simulation box. The \mbox{\hyperlink{classaabb_1_1_a_a_b_b}{AABB}} objects of individual particles are \char`\"{}fattened\char`\"{} before they are stored to avoid having to continually update and rebalance the tree when displacements are small.

Nodes are aware of their position within in the tree. The is\+Leaf member function allows the tree to query whether the node is a leaf, i.\+e. to determine whether it holds a single particle.
