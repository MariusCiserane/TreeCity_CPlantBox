\doxysubsection{Detailed Description}
Contains a parameter set describing as single sub type of an organ, specific parameters are then created with \mbox{\hyperlink{class_c_plant_box_1_1_organ_random_parameter_aa6989a0e7d9641c2a348764edcaa3103}{realize()}}.

Organizes parameters in hash-\/maps for scalar double and scalar int values. For this reason derived classes \mbox{\hyperlink{class_c_plant_box_1_1_organ_random_parameter_a0906dbac66fc789e4d761a28c672fc15}{get\+Parameter()}}, \mbox{\hyperlink{class_c_plant_box_1_1_organ_random_parameter_a9714debae54b412fb728c708b22eb0d0}{to\+String()}}, \mbox{\hyperlink{class_c_plant_box_1_1_organ_random_parameter_af93a5ecb718a11eac95d42dc7c8b86d3}{read\+XML()}}, and \mbox{\hyperlink{class_c_plant_box_1_1_organ_random_parameter_a5e2309b1ef1912a42be7106bbd09c91e}{write\+XML()}} should work out of the box. For other parameter types the methods must be overwritten, see e.\+g. \mbox{\hyperlink{class_c_plant_box_1_1_root_random_parameter}{Root\+Random\+Parameter}}.

The factory function \mbox{\hyperlink{class_c_plant_box_1_1_organ_random_parameter_afd1204de6d2c3b96969f856fbb767a5a}{copy()}} has to be overwritten for each specialization.
