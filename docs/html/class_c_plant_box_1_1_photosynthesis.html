Detailed Description

Photosynthesis computation according to Tuzet (2003), Dewar 2002 and Lu 2020 see also photosynthesis.py in CPlantBox/src/python_modules

Units are [cm] and [day]

Wraps a MappedSegments class (i.e. MappedPlant)
