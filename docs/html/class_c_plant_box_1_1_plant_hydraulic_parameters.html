Detailed Description

Plant hydraulic conductivities, i.e. axial [cm3/day] and radial [cm/day] conductivities

defined by the functions: kr_f(int segment_index, double age, int subType, int organType) kx_f(int segment_index, double age, int subType, int organType)

The parameters can be given per organType and subType:

  • constant
  • per segment
  • age dependent
  • distance dependent

Sets the radial conductivity [day-1] in an age dependent way, organ type and sub-type dependent

The value is linearly interpolated between the sampling points given by age, and values dependent on age, Extrapolation of the last value is used if age lies outside the domain defined by the sampling points.
