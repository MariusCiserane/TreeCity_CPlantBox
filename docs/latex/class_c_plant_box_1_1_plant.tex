\doxysubsection{Detailed Description}
\mbox{\hyperlink{class_c_plant_box_1_1_plant}{Plant}}

This class manages all model parameters, the simulation, and stores the seed of the plant, and offers utility functions for post processing.

The \mbox{\hyperlink{class_c_plant_box_1_1_plant}{Plant}} class inherits from \mbox{\hyperlink{class_c_plant_box_1_1_organism}{Organism}} and provides additional functionality\+:
\begin{DoxyItemize}
\item Manages the Organ\+Random\+Parameters
\item Offers an interface for the simulation loop (initialize, simulate, ...)
\item Collects node and line segment geometry from the organ tree
\item Collect parameters from the organs
\item Can collect information about the last time step
\item Supports RSML
\item Holds global node index and organ index counter
\item Holds random numbers generator for the organ classes 
\end{DoxyItemize}
