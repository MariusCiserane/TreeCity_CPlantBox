124 /*
125  * -----------------------------------------------------------------
126  * PART II: functions exported by sunlinsol_klu
127  *
128  * CONSTRUCTOR:
129  * SUNLinSol_KLU creates and allocates memory for a KLU
130  * sparse-direct linear solver
131  *
132  * SUNKLU (deprecated) wrapper for SUNLinSol_KLU
133  *
134  * OTHER:
135  * SUNLinSol_KLUReInit reinitializes memory and flags for a new
136  * factorization (symbolic and numeric) to be conducted at the
137  * next solver setup call. This routine is useful in the
138  * cases where the number of nonzeroes has changed or if the
139  * structure of the linear system has changed which would
140  * require a new symbolic (and numeric factorization).
141  *
142  * The reinit_type argument governs the level of
143  * reinitialization:
144  *
145  * reinit_type = SUNKLU_REINIT_FULL
146  * The Jacobian matrix will be destroyed and a new one will
147  * be allocated based on the nnz value passed to this call.
148  * New symbolic and numeric factorizations will be
149  * completed at the next solver setup.
150  *
151  * reinit_type = SUNKLU_REINIT_PARTIAL
152  * Only symbolic and numeric factorizations will be
153  * completed. It is assumed that the Jacobian size has not
154  * exceeded the size of nnz given in the sparse matrix
155  * provided tothe original constructor routine (or the
156  * previous SUNKLUReInit call)
157  *
158  * This routine assumes no other changes to solver use are
159  * necessary.
160  *
161  * SUNLinSol_KLUSetOrdering sets the ordering used by KLU for
162  * reducing fill in the linear solve. Options for
163  * ordering_choice are:
164  * 0 for AMD,
165  * 1 for COLAMD, and
166  * 2 for the natural ordering.
167  * The default is 1 for COLAMD.
168  *
169  * SUNKLUReInit (deprecated) wrapper for SUNLinSol_KLUReInit
170  *
171  * SUNKLUSetOrdering (deprecated) wrapper for
172  * SUNLinSol_KLUSetOrdering
173  *
174  * -----------------------------------------------------------------
175  */
