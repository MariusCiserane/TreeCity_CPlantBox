Detailed Description

Phloem flow based on PiafMunch code of LAcointe et al. 2019 see also phloem_flow.py in CPlantBox/src/python_modules

Units are [hPa] and [day] CplantBox object making link with PiafMunh Wraps a Photosynthesis class
