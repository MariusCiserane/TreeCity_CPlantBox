\doxysubsection{Detailed Description}
\mbox{\hyperlink{class_c_plant_box_1_1_plant}{Plant}} hydraulic conductivities, i.\+e. axial \mbox{[}cm3/day\mbox{]} and radial \mbox{[}cm/day\mbox{]} conductivities

defined by the functions\+: kr\+\_\+f(int segment\+\_\+index, double age, int sub\+Type, int organ\+Type) kx\+\_\+f(int segment\+\_\+index, double age, int sub\+Type, int organ\+Type)

The parameters can be given per organ\+Type and sub\+Type\+:
\begin{DoxyItemize}
\item constant
\item per segment
\item age dependent
\item distance dependent
\end{DoxyItemize}
