100  arguments obligatoires :
101 
102  f(double t, double* y, double* ydot) : fonction exprimant le systeme a resoudre : ydot[] = dy[]/dt en fonction de t et de y.
103  y : Fortran_vector des variables d'etat decrivant le systeme ; doit etre initialise a y0 = y(t=t0) avant l'appel du solveur.
104  T : Fortran_vector specifiant les valeurs de t pour lesquelles on desire la solution, y compris le temps initial t0 = T[1].
105  aux(double t, double* y) : definit une tache auxiliaire (NULL si aucune) a executer a chacun des instants t de T demandes
106  et egalement aux eventuels instants t solutions de rootfind (cf. ci-apres).
107  atol, rtol : (Fortran_Vector) precision absolue, relative -> erreur sur y[i] ~ ewt[i]= (rtol[i]* |y[i]|) + atol[i];
108  si xtol (= atol ou rtol) est de size 1, alors pour chaque composante (i= 1 a neq), xtol[i] = xtol[1].
109  Actuellement, seule la forme scalaire de rtol est geree ; l'option CV_WF de cvode (p. ...) n'est pas encore geree.
110 
111 arguments facultatifs pour le calcul des derivees de variables accessibles mais ne figurant pas dans le vecteur y des var. 'reservoirs' verifiant dy/dt = f(t, y, y') :
112 
113  NbVar_dot : nb de variables (Fortran_vectors) dont on souhaite la derivee a chaque instant.
114  Fortran_vector** Var_primitive : tableau (de taille NbVar_dot) des adresses des NbVar_dot variables (Fortran_vectors) dont on souhaite la derivee a chaque instant.
115  Fortran_vector** Var_dot : tableau (de taille NbVar_dot) des adresses des NbVar_dot derivees (Fortran_vectors) dont on souhaite la valeur a chaque instant.

117 arguments facultatifs annexes :

119  solver : (int) -- un des 2 ou 3 disponibles, suivant la fonction : {DENSE (par defaut), BAND, DIAG ou KLU} pour cvode_direct ; {SPGMR (par defaut), SPFGMR, SPBCGS, PCG ou SPTFQMR} pour cvode_spils.
120  GSType : (spec. cvode_spils) int (ignore si solver <> SPGMR ou SPFGMR) type d'orthogonalis. Gram-Schmidt: CLASSICAL_GS ou (par defaut) MODIFIED_GS.
121  prectype: (spec. cvode_spils) int : une des 4 constantes {PREC_NONE (par defaut), PREC_LEFT, PREC_RIGHT, PREC_BOTH} : le type de precond. de la mat.
122  verbose: booleen (true par defaut) : si true => affiche le deroulement (pas par pas) ;
123  STALD : (spec. cvode_xxxx) : booleen (true par defaut) : si true => active l'algorithme de detection/corr. d'instab. lie aux ordres >2.
124  rootfind : (spec. cvode_xxxx) : fonction (NULL si aucune) definissant un systeme de nrootfns eq. a resoudre en cours
125  d'integration : g[i](t, y) = 0 [i = 1..nroots]. Decl. suivant le prototype: rootfind(double t, double* y, double* g).
126  nrootfns : (spec. cvode_xxxx) : int : nombre d'equations g[i](t, y) = 0 (ci-dessus) eventuellement a resoudre ; ignore si rootfind = NULL.
127  mu, ml : (spec. cvode_xxxx) : int : pris en compte seulement si solver = BAND ou si prectype <> PREC_NONE : nb de super-diag. resp. superieures et inferieures.
128  maxl : (spec. cvode_spils) : int (= 5 par defaut) : la taille max. du sous-espace de Krylov.
