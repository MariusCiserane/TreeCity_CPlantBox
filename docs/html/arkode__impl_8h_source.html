414 /*---------------------------------------------------------------
415  Communication between ARKode and a ARKode Linear Solver
416  -----------------------------------------------------------------
417  convfail (input to lsetup)
418 
419  ARK_NO_FAILURES : Either this is the first lsetup call for
420  this step, or the local error test failed on
421  the previous attempt at this step (but the
422  Newton iteration converged).
423 
424  ARK_FAIL_BAD_J : This value is passed to lsetup if
425 
426  (a) The previous Newton corrector iteration
427  did not converge and the linear solver's
428  setup routine indicated that its Jacobian-
429  related data is not current
430  or
431  (b) During the previous Newton corrector
432  iteration, the linear solver's solve
433  routine failed in a recoverable manner
434  and the linear solver's setup routine
435  indicated that its Jacobian-related data
436  is not current.
437 
438  ARK_FAIL_OTHER : During the current internal step try, the
439  previous Newton iteration failed to converge
440  even though the linear solver was using
441  current Jacobian-related data.
442  --------------------------------------------------------------*/
443 
444 /* Constants for convfail (input to lsetup) */
445 #define ARK_NO_FAILURES 0
446 #define ARK_FAIL_BAD_J 1
447 #define ARK_FAIL_OTHER 2
448 
449 /*---------------------------------------------------------------
450  ARKLinsolInitFn
451  ---------------------------------------------------------------
452  This function should complete initializations for a specific
453  ARKode linear solver interface, such as counters and statistics.
454  This should return 0 if it has successfully initialized the
455  ARKode linear solver interface and a negative value otherwise.
456  If an error does occur, an appropriate message should be sent
457  to the error handler function.
458  ---------------------------------------------------------------*/
459 
460 /*---------------------------------------------------------------
461  ARKLinsolSetupFn
462  ---------------------------------------------------------------
463  This function should prepare the linear solver interface for
464  subsequent calls to the ARKLinsolSolveFn routine. It may
465  recompute Jacobian-related data is it deems necessary. Its
466  parameters are as follows:
467 
468  arkode_mem - void* problem memory pointer of type ARKodeMem. See
469  the typedef earlier in this file.
470 
471  convfail - a flag to indicate any problem that occurred during
472  the solution of the nonlinear equation on the
473  current time step for which the linear solver is
474  being used. This flag can be used to help decide
475  whether the Jacobian data kept by a ARKode linear
476  solver needs to be updated or not.
477  Its possible values have been documented above.
478 
479  tpred - the time for the current ARKode internal step.
480 
481  ypred - the predicted y vector for the current ARKode internal
482  step.
483 
484  fpred - f(tpred, ypred).
485 
486  jcurPtr - a pointer to a boolean to be filled in by lsetup.
487  The function should set *jcurPtr=SUNTRUE if its Jacobian
488  data is current after the call and should set
489  *jcurPtr=SUNFALSE if its Jacobian data is not current.
490  Note: If lsetup calls for re-evaluation of
491  Jacobian data (based on convfail and ARKode state
492  data), it should return *jcurPtr=SUNTRUE always;
493  otherwise an infinite loop can result.
494 
495  vtemp1 - temporary N_Vector provided for use by lsetup.
496 
497  vtemp3 - temporary N_Vector provided for use by lsetup.
498 
499  vtemp3 - temporary N_Vector provided for use by lsetup.
500 
501  This routine should return 0 if successful, a positive value
502  for a recoverable error, and a negative value for an
503  unrecoverable error.
504  ---------------------------------------------------------------*/
505 
506 /*---------------------------------------------------------------
507  ARKLinsolSolveFn
508  ---------------------------------------------------------------
509  This routine must solve the linear equation P x = b, where
510  P is some approximation to (M - gamma J), M is the system mass
511  matrix, J = (df/dy)(tcur,ycur), and the RHS vector b is input. The
512  N-vector ycur contains the solver's current approximation to
513  y(tcur) and the vector fcur contains the N_Vector f(tcur,ycur).
514  The input client_tol contains the desired accuracy (in the wrms
515  norm) of the routine calling the solver; the ARKDLS solver
516  ignores this value and the ARKSPILS solver tightens it by the
517  factor eplifac. The input mnewt is the current nonlinear
518  iteration index (ignored by ARKDLS, used by ARKSPILS).
519 
520  Additional vectors that are set within the ARKode memory
521  structure, and that may be of use within an iterative linear
522  solver, include:
523 
524  ewt - the error weight vector (scaling for solution vector)
525 
526  rwt - the residual weight vector (scaling for rhs vector)
527 
528  The solution is to be returned in the vector b. This should
529  return a positive value for a recoverable error and a
530  negative value for an unrecoverable error. Success is
531  indicated by a 0 return value.
532  ---------------------------------------------------------------*/
533 
534 /*---------------------------------------------------------------
535  ARKLinsolFreeFn
536  ---------------------------------------------------------------
537  This should free up any memory allocated by the linear solver
538  interface. This routine is called once a problem has been
539  completed and the linear solver is no longer needed. It should
540  return 0 upon success, or a nonzero on failure.
541  ---------------------------------------------------------------*/
542

802  should be stored here
